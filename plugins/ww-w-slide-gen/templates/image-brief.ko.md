# 페이지 디자인 의뢰서

[English](image-brief.md) | 한국어

이 의뢰서는 완결된 슬라이드 한 장에 사용합니다. 생성 전에 모든 항목을 채우세요.

- 페이지 ID:
- 대상 독자:
- 핵심 주장:
- 정확한 제목:
- 정확한 본문 카피:
- 필요한 증거와 원본 스크린샷 경로:
- 레이아웃 패턴:
- 테마 색상과 각각의 의미:
- 타이포그래피, 여백, 시각 참조 경로:
- 일러스트 지시사항:
- 텍스트 제거 시 보존할 요소:

간격은 필수 조건입니다. 모든 프롬프트에 명시하세요.
- 제목, 부제, 도식, 카드, 라벨 등 모든 컴포넌트 사이에 넉넉하고 고른 간격을 둡니다. 최소 간격을 px로 적으세요(블록 사이 40px 이상, 형제 카드 사이 24px 이상).
- 모든 카드와 패널 안쪽 여백은 일정하게 32px 이상으로 합니다.
- 같은 급의 요소는 간격을 똑같이 하고, 슬라이드 가장자리에서 80px 이상 띄웁니다. 컴포넌트가 서로 닿거나 붙지 않게 하고, 라벨이 도형에 바짝 붙지 않게 합니다.
- 화면이 빽빽하면 간격을 줄이지 말고 내용을 줄이거나 작게 하세요.
- 생성 후 이미지에서 간격을 확인합니다. 붙어 있는 쌍이 있으면 그 쌍을 지목해 다시 생성하세요.

완결된 16:9 슬라이드 디자인을 만드세요. 1920×1080을 요청하세요. 제공된 텍스트를 첫 구성에 포함하세요. 실제 스크린샷을 참조로 사용하세요. 증거나 수치 결과를 지어내지 마세요. 승인된 참조 스타일과 일치시키세요.

승인 후, 이 이미지에서 슬라이드 타이포그래피만 제거하세요. 아트워크, 여백, 구성은 유지하세요. 실제 스크린샷 텍스트는 그대로 두세요. 최종 슬라이드는 제목, 본문, 라벨, 페이지 번호를 편집 가능한 HTML로 복원합니다.

제출한 프롬프트, 선택한 출력 경로, 실제 픽셀 크기, 검토 메모를 프로젝트에 기록하세요. 소스 템플릿은 이미지 생성을 자동으로 호출하지 않습니다.
