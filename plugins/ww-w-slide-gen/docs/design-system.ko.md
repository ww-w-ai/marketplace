# 기본 소개서 디자인 시스템

[English](design-system.md) | 한국어

권위: 편집 가능한 참조 정의. 실제 구현 값은 `html/theme.css`에 있습니다.

## Foundations

따뜻한 흰색 배경, 짙은 잉크색 텍스트, 의미를 담은 짙은 청록, 큰 강조에 쓰는 노랑. Pretendard는 regular·bold·black 굵기가 번들되어 있습니다. 캔버스는 1920×1080이며 좌우 여백은 72px입니다. 제목은 80px/1.12, 본문은 32px/1.5, 표지 제목은 132px입니다. 카드 모서리는 24px입니다. 간격은 8, 16, 24, 32, 48, 72px을 따릅니다. 아트워크는 z0, 콘텐츠는 z1, 주석은 z2에 놓입니다. Reduced motion에서는 전환 효과가 꺼집니다.

## Components

`.s-title`, `.s-eyebrow`, `.s-lead`, `.s-footer`, `.s-pagenum`, `.card`, `.chip`, `.evidence`, `.art`, `.cover`. 컴포넌트는 테마 토큰을 사용합니다. `.slide`의 직접 자식은 각각 독립적으로 움직일 수 있는 에디터 객체입니다. 관련 요소는 의도적으로 그룹으로 묶으세요.

## Patterns

표지, 3열 콘텐츠, 스크린샷 증거, 프로세스, 비교표, 네이티브 텍스트가 있는 이미지 아트워크. 예제는 `html/pages/`에 있습니다. 페이지 전용 좌표는 `html/pages.css`에 있습니다.

## Guidelines

한 페이지에 하나의 주장만 담습니다. 증거로는 검증된 스크린샷을 사용합니다. 실제 화면 콘텐츠를 제외하면 텍스트는 항상 네이티브 HTML로 남습니다. 스크린샷 비율을 유지합니다. 작은 캡션과 장식용 라벨은 피합니다. 기본 간격을 일관되게 유지합니다. 가장 긴 실제 문구와 최종 PDF를 확인합니다. 예시 팔레트는 교체 가능하며, 새 브랜드마다 반드시 따라야 하는 요구사항이 아닙니다.
