# 생성한 이미지 시안을 편집 가능한 장표로 만드는 법

[English](image-workflow.md) | 한국어

1. 장표별 주장·본문·증거·레이아웃을 먼저 확정합니다.
2. 디자인 시스템과 승인된 기준 장표를 함께 입력해 **각 페이지 전체 시안**을 개별 생성합니다. 정확한 문구를 포함해 디자인을 완성합니다.
3. 실제 출력 이미지의 가로·세로 크기를 확인하고 기준 시안을 `assets/reference/`에 보관합니다. 1920×1080 요청만으로 실제 크기를 단정하지 않습니다.
4. 시안에서 제목·본문·배지·라벨·페이지 번호만 제거합니다. 레이아웃·배경·일러스트는 유지합니다. 결과를 `assets/backgrounds/`에 보관합니다.
5. `.art` 이미지로 배치하고 동일한 위치에 HTML 텍스트를 얹습니다. 예제는 `html/pages/06-artwork.html`입니다.
6. 실제 서비스 화면은 `assets/screenshots/`에 저장한 캡처 원본을 별도 `<img>`로 넣습니다. 생성 과정에서 변형된 수치와 글자를 증거로 사용하지 않습니다.
7. 기준 시안과 최종 HTML을 대조합니다. 생성 이미지의 글자가 남아 중복되지 않는지, 모든 설명 텍스트가 편집되는지 확인합니다.
8. 라이브 편집본 다운로드와 전체 PDF를 확인합니다.

기본 이미지 생성은 Codex 내장 `image_gen`을 사용합니다. Claude Code에서는 Codex CLI가 설치돼 있으면 같은 작업을 비대화형으로 Codex에 위임합니다. 예:

```sh
codex exec --skip-git-repo-check -C /absolute/path/my-deck -s workspace-write "<지시: 내장 image_gen 사용, 전체 프롬프트, 대상 경로>"
```

자산 하나당 한 번 호출하고, 호출이 끝나면 파일이 실제로 생성됐는지 확인합니다.

Codex를 쓸 수 없으면 브라우저로 ChatGPT를 조작합니다. 브라우저 자동화 도구(browser-use, Claude in Chrome)가 로그인된 브라우저에서 chatgpt.com을 열고, 같은 프롬프트를 보내고, 이미지를 `assets/`에 내려받습니다. 둘 다 없으면 해당 호스트가 제공하는 이미지 도구를 사용합니다. 빌드 자체는 이미지 생성 API를 호출하지 않습니다.

## 페이지별 의뢰 원본

`templates/image-brief.md`를 복사합니다. 동일 디자인 규칙을 매 페이지 의뢰에 포함하고 페이지별 내용과 증거만 교체합니다. 실제 캡처가 필요한 페이지는 캡처부터 확보합니다.

## 기존 AI 지우개

원본 편집기의 MI-GAN 연결 코드는 유지했지만 모델 가중치와 ONNX 런타임은 배포하지 않습니다. 기본값 `features.aiEraser=false`에서는 버튼을 숨깁니다. 일반 텍스트 편집·이미지 자르기·단색 덮개는 사용할 수 있습니다.

가중치 사용 권한을 확인하고 기능이 필요한 프로젝트만 `html/vendor/ort/ort.wasm.min.js`와 그 WASM/MJS 의존 파일, `html/vendor/migan_pipeline_v2.onnx`를 준비한 뒤 설정을 true로 바꿉니다. 배포 시 해당 라이선스도 포함합니다. 빌드 결과 HTML에는 이 선택적 모델이 포함되지 않으므로 다운로드본에서 새 AI 지우개 작업은 보장되지 않습니다. 이미 지운 이미지는 데이터 URL로 저장됩니다.
