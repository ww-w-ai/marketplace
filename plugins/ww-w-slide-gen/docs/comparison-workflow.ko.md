# 원본 비교 → 최종본 제작

[English](comparison-workflow.md) | 한국어

권위: 제작 절차. 원본 디자인은 이미지 생성으로 만들고, 퍼블리셔는 승인된 구성을 재현한다.

1. 원본 이미지와 원본 캡처를 보존한다.
2. 복잡한 아트의 글자만 제거하고 HTML/CSS로 편집 가능한 글자를 얹는다. 단색 면은 CSS로 만든다.
3. `comparison.config.json`에 **홀수: 원본 / 짝수: 퍼블리싱**을 같은 `pair`로 등록한다.
4. `npm run build:compare`로 비교본을 만든다. 같은 뷰포트에서 번갈아 보며 배치·글꼴·색·여백·줄바꿈을 대조한다.
5. 퍼블리싱만 수정한다. 글자의 비균등 확대·축소는 금지한다. 설명선은 설명에 해당하는 실제 대상에서 시작해야 한다.
6. 라이브 편집을 소스에 반영한 후 `npm run build:final`을 실행한다.
7. 명령은 비교 설정을 별도 `final.config.json`으로 복제하고, **복제본에서만 원본 장표 항목을 제외**한다. 기존 빌더로 독립 HTML을 만든다. 비교 설정·원본 장표·원본 자산은 삭제하지 않는다.
8. 최종본에 원본 장표가 없고 순서·편집·저장·인쇄가 정상인지 확인한다. 비교 통과가 사용자 승인 자체를 뜻하지는 않는다.

최종 HTML은 자산이 포함된 독립 스냅샷이다. 소스 HTML/CSS는 공유하므로 이후 재빌드하면 최신 수정이 반영된다. 최종본의 수동 편집을 보존하려면 재빌드 전에 소스로 옮긴다.

## 설정

`templates/comparison.config.json`을 루트로 복사하고 실제 페이지·스타일·브랜드 경로로 바꾼다. 템플릿의 경로는 예시이며 자동으로 페이지를 만들지 않는다.

```json
{"file":"pages/reference-01.html","role":"reference","pair":"cover"}
{"file":"pages/published-01.html","role":"published","pair":"cover"}
```

`final`의 출력 파일명·다운로드 파일명·편집 저장 키는 비교본과 다르게 둔다. 생성된 `final.config.json`은 직접 수정하지 않는다. 최종본 생성은 디자인 승인이나 문구 변경을 자동 수행하지 않는다.
